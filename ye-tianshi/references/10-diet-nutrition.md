## 一、瘥后调理公式

**公式 A（热病愈后第一律）**：
`热病后（余热未尽）＝乱进食物 × 便是助热 → 忌荤腻厚味，进清淡之味 → 蔬粥养胃`
配套风险：`乱食 → 食复`；`多言、行走劳动 → 劳复`；二者合称"食复劳复"，为热病两大复发途径。

- **【原文】**（《临证指南医案·暑门》叶案）"故乱进食物，便是助热。惟清淡之味，与病不悖。自来热病，最怕食复劳复，举世共闻，非臆说也。"（02 第3734–3735行）
- **【原文】**（同上·产后）"勿进荤腻，恐滞蒸化热。蔬粥养胃，以滋清润燥。"（02 第789行）
- **【原文】**（《叶氏医案存真》）"时热食复，胸痞，恶心欲呕，进半夏泻心法。"（03 第1467行）——示食复之典型症候为胸痞呕恶。
- **【原文】**（《临证指南医案·疟门》叶案）"疟后食大荤太早，胃气受伤，不得下降，致痞闷恶心，痰多唇燥。"（02 第4389行）——食复的机制：厚味**过早**、**壅滞胃气**使胃失和降。

**公式 B（劳复的界定）**：
`病后多言伤气 + 行走动筋 = 劳复 → 治以甘温和养气血（建中类）`
- **【原文】**"病后精采未复，多言伤气，行走动筋，谓之劳复。当与甘温和养气血。"（02 第337行）——叶氏对"劳复"给出的最明确定义，落点在心（言）与筋（行）两处耗气。
- 旁证：【原文】"近日冬温，引动宿病，加以劳复。"（02 第3614行）；"疟后劳复"（02 第4435行）。

**公式 C（瘥后总纲·寝食为先）**：
`察瘥后安危 = 首问"浆粥能进否"（验胃气） + "寤寐如常否"（验神思）`
- **【叶氏编定】**（《叶选医衡·寝食说》）"经云：调寝食在医药之先……夫色声既受，非安谷不能生精与气，非安枕不能养血与神。是以百病阽危，必首论云浆粥能进否，验其胃气之败与不败；寤寐如常否，察其神思之宁与不宁。"（04 第1215行）
- **【叶氏编定】**"不食少卧病也，多食嗜卧亦病也。卫生却病者，能不谛当于寝食间哉？"（04 第1216行）

**公式 D（久虚瘥复）**：
`久虚劳怯 → 屏绝酒色怒烦 + 安闲坐卧百日 → 胃口渐旺 → 精生于谷食`
- **【原文】**（《叶氏医案存真》）"此恙屏绝酒色怒烦，须安闲坐卧百日，必胃口渐旺，病可渐除，古称精生于谷食也。"（03 第588行）
- **【原文】**（《临证指南医案·脾胃门》叶案）"病后胃气不苏，不饥少纳，姑与清养。"（02 第2523行）——瘥后调理之正法为"清养"，非峻补。

## 二、病中饮食禁忌公式

**公式 A（按邪性分忌）**：
- `温病／冬温 → 忌汗、忌下、忌辛温（酒醴辛辣）`：**【原文】**"仲景谓：发热而渴者，为温病……治法清热存阴，勿令邪热焚劫津液……且忌汗、忌下、忌辛温。"（03 第774行）；**【原文】**"最忌辛温重药"（03 第1479行）；**【原文】**"凡辛温气味宜戒"（02 第2121行）。
- `湿温／湿热 → 忌甜腻厚味、忌酒肉`：**【原文】**"酒客里湿素盛，外邪入里，与之相抟"（01《温热论·论湿邪》）；**【原文】**"腥膻重味宜忌"（03 第699行）；"当忌酒肉厚味"（第216行）；"当忌荤酒浊味"（第351行）；"酒肉闭气，食物宜忌"（第831行）。
- `热在上／头面诸窍、疮疡 → 忌辛辣腥鲜浊味`：**【原文】**"治在少阳，忌食腥浊"（02 第361行）；**【原文】**"辛辣腥鲜勿进。尚可缓以计功"（02 第479行）。
- `胃痛／胃阴伤 → 忌刚燥，宜淡味薄味`：**【原文】**"宜淡味薄味清养"（02 第197行）；**【原文】**"宜薄滋味庶杜疟患"（02 第3722行）；**【原文】**"当薄味以和上焦"（02 第2069行）。

**公式 B（反对盲目禁食·重要纠偏）**：
`热病初起 ≠ 绝谷断食；幼科"禁绝乳食"必致胃气索然 → 忌绝谷`
- **【原文】**（《临证指南医案·幼科要略》）"春月暴暖忽冷，先受温邪……辛解忌温，只用一剂，**大忌绝谷**。"（02 第1246行）
- **【门人总结】**"初则发散解肌……再令病家禁绝乳食，每致胃气索然，内风来乘，变见惊痫，告毙甚多。"（02 第981–982行）——明斥世俗"禁食退热"之弊。

**公式 C（时序/旧病新病）**：
`先治新病，后理宿病`；瘥后进补须待"谷食已安"。
- 参见第一节公式A、D；**【原文】**"今谷食已安，谅无反复"（02 第783行）。

## 三、脾与饮食公式

**公式 A（纳运分工·叶氏核心命题）**：
`纳食主胃（受纳） + 运化主脾（转输）＝ 后天之本`；故治饮食病须分"受纳之权"与"运化之职"。
- **【原文】**（《临证指南医案·疡科》叶案）"纳食主胃，运化主脾。痈疡痛溃，卧床不得舒展，脏腑气机呆钝何疑……出纳之权交失。"（02 第508行）
- **【门人总结】**（《临证指南医案·脾胃门》按语，引叶氏立论）"纳食主胃，运化主脾。**脾宜升则健，胃宜降则和**。又云：太阴湿土，得阳始运；阳明阳土，得阴自安。以**脾喜刚燥，胃喜柔润**也。仲景急下存津，其治在胃；东垣大升阳气，其治在脾。"（02 第2551行）——叶氏脾胃分治的总纲，"升降"二字尤为紧要（02 第2554行）。
- **【叶氏编定】**（《寝食说》）"大抵多食易化，责在阳明之火；火食难化，责在太阴之虚。"（04 第1220行）——**能食而化不及＝脾虚；食多而善消＝胃火**。
- **【叶氏编定】**"大抵因多食而顿不能食者为实，从少食而渐不能食者为虚。"（04 第1218行）
- **【叶氏编定】**"有一脏之虚，必偏嗜一味，如怀孕之肝虚嗜酸者。"（04 第1219行）——**偏嗜＝脏腑偏虚之征**。

**公式 B（治胃大法·"通即是补"）**：
`胃阳土喜柔恶刚燥 → 治胃宜甘濡润、宜通降；治脾宜温运`
- **【原文】**"阳土喜柔偏恶刚燥。若四君异功等，竟是治脾之药。腑宜通即是补。甘濡润，胃气下行，则有效验。"（02 第2521–2522行）——脾胃分治的关键判据。
- **【原文】**"味淡短气"、"胃阳受伤，腑病以通为补。与守中必致壅逆"（02 第177、2526行）。
- **【门人总结】**（胎前门·秦天一）"胃为水谷之海，妊妇全赖水谷之精华以养身护胎，故胃气如兵家之饷道，不容一刻稍缓也。"（02 第743行）

**公式 C（谷气—血脉—冲任链）**：
`水谷盛 → 血气盛 → 冲任（月经）有本`；谷气衰则诸病由生。
- **【叶氏编定】**（《血营气卫论》）"人受谷于胃，胃为水谷之海，灌溉经络，长养百骸"（04 第161行）。
- **【叶氏编定】**（《内伤余议》）"夫胃受水谷，故清阳升而浊阴降，以传化出入，滋荣一身……今胃不纳谷，而谷气衰少，则清无升而浊无降矣。"（04 第778–779行）——**"谷气不盛"是内伤发热的起点**。

**公式 D（脾肾分工）**：
`脾阳宜动（动则运） + 肾阴宜藏（藏则固）`；脾为阴土，得阳乃运。
- **【原文】**（《叶氏医案存真》）"凡身中脾阳宜动，动则运。肾阴宜藏，藏则固。斯为病根。"（03 第558行）
- **【原文】**"以脾为阴土，得阳乃运"（03 第564行）。

## 四、"损谷"法则

**公式（食积/伤食的总纲·叶氏编定原文）**：
`水湿伤（无形之气）→ 发汗、利小便，上下分消`
`食积伤（有形之物）→ ①首法"损其谷"（减少食量、留其虚） → ②其次消导`
- **【叶氏编定】**（《叶选医衡·内伤余议》）"又曰：饮者无形之气，伤之则宜发汗利小便，使上下分消其湿；**食者有形之物，伤之则宜损其谷**，其次莫如消导。"（04 第774行）——**"损其谷"居消导之前，是叶氏对食伤的第一处理序位**。
- **【叶氏编定】**（《寝食说》）"凡饮食之节，减满受虚，故当饥而食，节其满未饱，先止留其虚。"（04 第1229行，引张侗初氏）——"损谷"的操作化表达：**未饱先止，留其虚**。
- **【叶氏编定】**"盖草木皆以治病，病去则五谷果菜肉皆补也。"（04 第187行）——病去之后，食养即补，不必药补。

**公式（食伤成积成疳的路径）**：
`食物不节／甘肥不节 → 脾胃受戕 → 停积发热 → 热久津干 → 疳`
- **【原文】**"食物不节。脾胃受戕。腹膨。大便不调。此属脾疳。"（02 第1385行）
- **【原文】**"能食。色枯形瘦。暮热泄泻。此皆口腹不慎。值长夏温热。脾胃受伤。将成五疳。"（02 第1386行）
- **【门人总结】**"疳者，干也。小儿肠胃柔嫩。若乳食失调，甘肥不节，运化不及，停积发热，热久津干。"（02 第1388行）

**公式（有滞当攻，无滞当补·辨证分界）**：
`饱食痛甚 = 有形之滞 → 当攻逐`；`得食痛缓、素虚烦劳 = 无形之虚 → 当甘温填补`
- **【门人总结】**"又如饱食痛甚，得食痛缓之类，于此有宜补不宜补之分焉……若有形之滞堵塞其中，容纳早已无权……攻之逐之等剂，又不可缓也。"（02 第204–205行）
- **【门人总结】**（痢疾门·纠偏）"今人以滞为食，但以消食，并令禁忌饮食而已"（02 第1107行）；"胃强善食者，苦寒清热，更节饮食"（02 第1115行）——**食滞不等于一概消导，亦不主张一味禁食**。
- **【原文】**"诸豆皆能闭气。浆凝为腐。宛是呆滞食物。"（02 第202行）——具体食忌之例。

## 五、四时养生观

**公式 A（"因体顺时"·非治病）**：
`春夏养阳（扶培生气） / 秋冬养阴（滋藏摄纳）＝ 论体之法，不与逐邪攻病同例`
- **【原文】**（《临证指南医案·虚劳门》叶案）"仿内经春夏养阳、秋冬养阴为法。**非治病也。乃论体耳。**"（02 第1835行）
- **【原文】**"即古圣春夏养阳，不与逐邪攻病同例。"（02 第1833行）；"经旨春夏养阳，重在扶培生气耳。"（02 第4828行）

**公式 B（时令 → 用药变量）**：
`夏月大气泄越、脾胃主令 → 不可过凉，宜清暑益气护脾胃`；`冬月宜藏 → 忌发散攻夺`
- **【门人总结】**"夏之月，大气正在泄越，脾胃主令，岁气天和，**保之最要**……午余天热气泄，必加烦倦，随用清暑益气之剂。"（02 第679行）
- **【叶氏编定】**（《运气说》）"天道虽难测，而运气尽其妙矣……观岁运之流行，即安危之关系。"（04 第126、129行）
- **【叶氏编定】**（《温病热病解》）"每以春夏之温热病，与秋冬之伤寒一类治之而无别。不知秋冬之伤寒，真伤寒也。"（04 第503行）

**公式 C（运气－体质合参）**：
`按"岁气＋体质"定调理方 → "方合岁气体质调理"`
- **【门人总结】**"正合岁气节候而设"（02 第1622行）；"方合岁气体质调理"（02 第2669行）。

> **⚠️ 核实声明**：《素问·五常政大论》"**必先岁气，毋伐天和**"一语，**未见于本四部源文件**（已全文检索核实；与本项目 `09-clinical-safety.md` 的核查结论一致）。四部文献的实际表述仅为"**岁气天和，保之最要**""**正合岁气节候**""**方合岁气体质调理**"及《叶选医衡·运气说》的胜复论。**调用时不得将"必先岁气"作为叶氏原文引用**。

## 六、房室/劳逸

**公式 A（养身论四条·叶氏编定总纲）**：
`避风寒保皮毛六腑 + 节劳逸保筋骨五脏 + 戒色欲以养精、正思虑以养神 + 薄滋味以养血、寡言语以养气`
- **【叶氏编定】**（《叶选医衡·养身论》）"避风寒以保其皮肤六腑……节劳逸以保其筋骨五脏……戒色欲以养精，正思虑以养神……薄滋味以养血，寡言语以养气。"（04 第108–109行）
- **【叶氏编定】**"《上古天真论》曰：饮食有节，起居有常，不妄作劳，精神内守，病安从来？……此保养之正宗也。"（04 第101行）
- **【叶氏编定】**"保养则于日用饮食，而为可法可经。"（04 第99行）——**养生落点在日用饮食起居，不在丹砂烹炼**（并斥"运任督久则生痈"等修养之弊，04 第99–100行）。

**公式 B（劳伤归脏）**：
`饮食失度伤脾 · 起居不慎伤肝 · 色欲纵肆伤肾`；`喜怒思虑伤心 · 忧愁恐哀伤肺`
- **【叶氏编定】**（《虚损宜分阴阳施治论》）"如喜怒思虑则伤心，忧愁恐哀则伤肺……饮食失度则伤脾，起居不慎则伤肝，色欲纵肆则伤肾。"（04 第251行）

**公式 C（叶氏医案的"绝欲/静养"指令）**：
`虚损、失血、遗精、劳怯 → 屏绝酒色怒烦 + 绝欲经年 + 安闲静养百日`
- **【原文】**"但酒色无病宜节，有病宜绝，经年之内屏绝，必得却病。"（02 第2115行）——**"无病宜节，有病宜绝"八字是叶氏房室观的最简表达**。
- **【原文】**"然须戒酒淡欲，怡情静养，水足火不妄动。"（02 第2121行）；"安闲绝欲可安"（02 第2122行）；"急宜绝欲静养"（02 第2230行）。
- **【原文】**同类指令之量化："绝欲一年，小暑艾灸，静养一百二十天可愈"（02 第3960行）；"静摄绝欲，经年可复"（03 第2505行）；"绝欲百日，助其收藏"（03 第3414行）；"必绝欲经年，可以却病"（03 第795行）；"勿与酒色伤损"（02 第2255行）。
- **旁证（前人医案附载）**"但不能薄滋味，远房室，则药虽应病，终无益于治疗也。惟智者善为调摄为第一义。"（03 第2559行，张石顽案）

## 七、饮酒与茶

### 7.1 酒：叶氏视酒为湿热之魁

**公式 A（酒性归经与害）**：
`酒性辛温慓悍 → 先入肝胆，次及胃 → 酿湿生热、动痰生风 → 酒客里湿素盛、易中易衄易淋`
- **【原文】**（《温热论·论湿邪》）"又有酒客里湿素盛，外邪入里，与之相抟。在阳旺之躯，胃湿恒多；在阴盛之体，脾湿亦不少。"（01）
- **【原文】**（《叶氏医案存真》）"脉涩小数，质弱，平昔喜饮。酒性先入肝胆，故易生嗔怒。"（03 第90行）——**酒伤肝胆 → 情志易怒**。
- **【原文】**"行走多动阳，酒湿多变热……酒性先入胆，次及胃。酒客性恶甜腻，从苦降定议，以苦能却湿也。"（03 第180行）——**酒客忌甜腻、宜苦降**。
- **【原文】**"淋属肝胆，而酒性湿热之气，肝胆先受，滓汁次及肠胃……不受温补，当忌酒肉厚味。"（03 第216行）
- **【原文】**"酒家湿胜于内，暑邪秽气亦由口鼻而入，内外相因，延蔓三焦。"（03 第1350行）；"酒性慓悍，致伤脏腑津液"（03 第1152行）；"膏粱酒醴，酿湿内著"（03 第657行）。
- **【叶氏编定·《酒人多中风说》】**"盖酒性温散，善解腠理，卫虚则外邪易入；酒气湿热，能酿痰涎，痰多则内风易动。"（04 第322行）"房劳致虚者固众，而沉湎致虚者尤多"（04 第320行）；"若酒色并嗜之流，又为双斧伐木，其仆可立而待"（04 第324行）。另"饮酒中风，亦名酒风"（04 第321行）。
- **【原文】**（病从口入之例）"食烧酒辛热，及青梅酸泄，遂衄血咳嗽，心腹极热。五味偏胜，腑阳脏阴为伤。"（02 第54行）；另"好饮冷酒"致胃痛（第187行）、"酒肉滞气胃痛"（第193行）、"酒性辛温，亦助湿热"（第2443行）。

**公式 B（酒亦入药·非饮用养生）**：
`酒醴通和血脉（药酒/外治），非教人饮酒`
- **【原文】**"灸刺无功，议用酒醴通和血脉"（03 第642行）；"三味投入无灰酒十斤，隔水煮。一日早晚暖服三四杯"（03 第648行，药酒方）；"议以酒醒之，是治风先治血之意"（03 第732行）。——**须辨明：此为药用酒剂，与叶氏"戒酒"之养生主张并行不悖。**

### 7.2 茶：叶氏以茶为"药"，未见"饮茶养生"专论

**核实说明**：四部源文件中，**"茶"均以药物或药引出现，未见叶氏论"日常饮茶养生／茶饮宜忌"的条文**。可得者三：

- **【原文】**（药茶）"以茶调散一钱，卧时用真苦丁茶一钱五分，煎汁调服，俾上窍内膜无阻。"（03 第1008行）；"苦丁茶"高频见于头面诸窍方（02 第117、119、354、361、365、370行等），功在**清少阳郁热、清上焦气热**。
- **【叶氏编定】**（异食癖之征）"有虫积为患，好食茶叶、生米、泥炭、草纸之类者。"（04 第1219行）——**嗜食茶叶在此被列为虫积／偏嗜病候**，非常法养生。
- **【叶氏编定】**"辄以桂、附为家常茶饭"（04 第727行）——"茶饭"仅作比喻，非论茶。

## 八、情志养生

**公式 A（七情本于五志，总归于心·叶氏编定）**：
`七情（喜怒忧思悲恐惊）＝ 五志（五脏）之扩充`；`情志之伤虽五脏各属，而"无不从心所发"`；`养心 → 志意和精神定 → 五脏俱安`
- **【叶氏编定】**（《叶选医衡·七情考》）"世之所谓七情者，即《内经》之五志也……然情有七，无非出于五脏。"（04 第1198行）
- **【叶氏编定】**"由此言之，是情志之伤，虽五脏各有所属，然求其所由，则无不从心所发……可见心为五脏六腑之大主。"（04 第1209–1210行）
- **【叶氏编定】**"设能善养此心，而居处安静，无为惧惧，无为欣欣，婉然从物而不争，与时变化而无我，则志意和，精神定，悔怒不起，魂魄不散，五脏俱安，邪亦安从奈我哉。"（04 第1211行）——**情志养生的操作描述：居处安静 + 不争 + 无我**。
- **【叶氏编定】**"养心莫善于寡欲"（04 第110行）。

**公式 B（五志化火·饮食与情志合邪）**：
`大怒火起于肝 + 醉饱火起于胃 + 房劳火起于肾 + 悲哀火起于肺 → 五志厥阳之火`
- **【叶氏编定】**（《火论》）"盖大怒则火起于肝，醉饱则火起于胃，房劳则火起于肾，悲哀动中则火起于肺，心为君主，自焚而死，此五志厥阳之火也。"（04 第685行）——**饮食（醉饱）与情志（怒、悲）、房劳并列为四大火源**。
- **【叶氏编定】**"大怒逆气伤肝，醇醴浓味伤胃，富贵者多有之"（04 第277行）。
- **【原文】**（《临证指南医案》）"内经五志过极，皆从火化"（02 第723行）。

**公式 C（"怡情放怀"＝叶氏处方之一）**：
`情志病 → 药力有限，须"怡情放怀""开怀安养""勿恃医药"`
- **【原文】**"胃脘常痛，情志不适即发……脾胃之土受克，却因肝木来乘。**怡情放怀，可愈此病**。"（02 第176行）——最凝练之句。
- **【原文】**"情怀忧郁，永不能痊。以内起情志，不专草木微功耳。"（02 第80行）——**"不专草木微功"是叶氏对情志病的根本判断**。
- **【原文】**"内损情怀少畅，非偏寒偏热可以攻病……开怀安养为宜。勿徒恃药。"（02 第583行）；"必得怡悦情怀，经来可挽"（02 第586行）；"情怀不得解释，草木无能为矣"（02 第4128行）。
- **【原文】**（《叶氏医案存真》）"务以情怀开爽为要，勿恃医药却病。"（03 第351行）
- **【门人总结】**（噎膈门·邹滋九）"夫噎膈一症，多因喜怒悲忧恐五志过极，或纵情嗜欲，或恣意酒食，以致阳气内结，阴血内枯而成。"（02 第3088行）——**情志 + 纵欲 + 酒食三因合力致病**。

**公式 D（睡卧之法·叶氏编定引录）**：
`先睡心（止法） → 后睡眼（观法）`
- **【叶氏编定】**（《寝食说》）"睡卧之法，先睡心，后睡眼。睡心是止法，睡眼是观法。能斯二者，始可与言养生。"（04 第1229–1230行）
- **【叶氏编定】**警示："世复有寝食无节之流，顾不食而纵酒，不寐而渔色，是又疾不干人，人来求疾。是以庄生云，人之可畏者，在衽席饮食之际，信矣。"（04 第1230行）
