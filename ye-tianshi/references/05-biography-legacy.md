# 叶天士·生平、学术传承与外部评价

> **依据**：以本地素材（《叶选医衡》六序＋自序、《叶氏医案存真》叶序／石叙／胡叙、《临证指南医案》门人按语、《温热论》题署）为第一依据，网络材料仅作补证并逐条标源。诸家互异者并列，无法确证者标"**待考**"，传说层标"**传说**"，后世评述标"**转述**"。

## 二、家世与师承

### 2.1 三代世医（新安—吴门双重底色）

- **曾祖**叶崖山，邑庠生（未业医）；**祖**叶紫帆（名时），通医理、擅儿科。
- **父**叶朝采，字**阳生**，精医，兼工书画、善鼓琴，轻财好施；与汪尧峰、**张路玉（张璐）**、沈明生、程应旄为友——张璐后亦列十七师之一，可证"师承"与"父执"两层网络重叠。**兄**叶又凡，亦精医。
（以上见《叶天士诊治大全》"第一章 叶氏生平"，**转述**。）

### 2.2 "十七师"的名单与证据强度

各家名单略异，较一致的八人为：**王子接（字晋三）、徐时进、马元仪、周扬俊、祁正明、张路玉、柯韵伯、魏荔彤**（《叶天士诊治大全》等）。

**本地硬证据**：《叶氏医案存真》叶万青序称"天元医案中，载马元仪先生案颇多……而**祁正明、王晋三两先生之案亦附焉**"——二人之案被叶氏后人视为可与叶案并列，可证承接。

**两点须注意**：《清史稿》本传不载师承细节，仅言"从学于父之门人"；梁章钜则称其"闻某人善治某证，即往执弟子礼，**既得其术，辄弃去**"。"十七"系通行概数，名单各本互异，**待考**。传说改名投山东刘姓名医学针术、入金山寺向老僧学医等（**传说**），仅存目。

## 三、弟子与著述群体

### 3.1 可确考者（有本地一手题署）

| 姓名 | 身份／事功 | 本地证据 |
|---|---|---|
| **顾景文** | 录《温热论》，叶氏温病学说传世的关键人物 | 《温热论》题署"清 叶桂 述 **门人 顾景文 录**" |
| **华岫云** | 采辑编《临证指南医案》；另有"华岫云本"《温热论》 | 《温热论》题"**华岫云本**"；本地叶序"先高祖《临症指南》一书，为**锡山华君岫云所刻**，书成于乾隆丙戌" |
| **周仲升** | 日侍门诊抄录，成《未刻本叶氏医案》（题"古吴小狂周显仲升集"） | 网络**转述**，本地无直接证据 |

此表本身即"叶派"第一手证据：按语（如《衄》门邵新甫、《疝》门邹滋九、《头痛》门邹时乘、《产后》门龚商年、秦天一）系统归纳叶氏治法结构，构成叶学**注疏传统**。本地另附"**徐评**"69 处（徐灵胎批语过录），说明通行本《临证指南》历来是"叶案＋门人按语＋徐批"三层并置之文本。

### 3.3 家族与门人全景（**转述**）

沈德潜《叶香岩传》记："配潘孺人，子二：奕章、龙章。亦善医，以君名掩。孙二人，曰堂，曰坚。曾孙三人，习儒业。"《叶天士诊治大全》所记合（曾孙钟、铨、钧，与《本事方释义》1803 年由"曾孙叶钟等校刊"相合）。门人称"满吴中，如吴蒙、姚亦陶、陆禹川、周仲升、吴坤安等数十人"（各本用字互异）。

### 3.4 "编者是否弟子"之争

《四库全书总目提要》评《临证指南医案》："乃门人取其方药治验，分门别类，集为一书，附以论断，**未必尽桂本意也**。"胡震远《考证〈临证指南医案〉编者及刊行与注评时间》（《中医杂志》1980 年第 11 期）进而提出"编者都不是叶天士的学生"。沈英森《临证指南医案发挥》反驳：应计入"私淑弟子"，华岫云编书距叶氏卒年未远，"若真不是门生亦胜似门生"（**两说并存**）。

## 四、核心著作

| 著作 | 性质·成书与版本 | 评价 |
|---|---|---|
| **《温热论》**（又名《温热证治》／章楠改题《外感温证篇》） | 叶氏口授、顾景文舟中笔录，非手定。本地本署"华岫云本"；首刊唐大烈《吴医汇讲》卷一（1792），后为华岫云《续选临证指南》收录改名 | 《清史稿》称"传为口授门人顾景文者"；柳序推为叶氏唯一"言皆精要，语不游移，**洵可法可传**" |
| **《临证指南医案》**十卷 | 门人华岫云等采辑三年，"附以论断"。刊年两说：**1766（乾隆丙戌）**——本地叶序；**1764（乾隆二十九年）**——沈英森书。**待考** | 《清史稿》明言"非其自著"；沈英森谓当时几于"每位医生案头都恭置一部"（**转述**） |
| **《叶选医衡》**二卷 | 题叶桂选定，选历代论病论脉论治之文七十余篇，"削繁就简，折衷一是"。本地序跋时序：**曹元恒**（光绪十六年，1890）、**柳宝诒**（光绪二十年，1894）、**缪萼聊**（同年）、**金文钟**（宣统二年，1910）、**顾梦熊**（同年）；曹序记"庚申之变，板毁于兵"（当指咸丰十年，1860） | 柳序："其书虽采自前人，而网罗宏富，抉择精严，其不惬于理者，又经改定，间附论说" |
| **《叶氏医案存真》**三卷 | 家藏方案，裔孙汇编。本地叶序署道光壬辰（1832），石叙、胡叙署道光丙申（1836）；附马元仪、祁正明、王晋三案 | 石叙："至今谈方术者，必举其姓字，以为**仲景、元化一流人也**" |
| **《未刻本叶氏医案》**二卷 | 周仲升侍诊逐日抄录，"未曾经过修饰整理者"。抄本经张耀卿收藏，程门雪校读并作《校读记》（1944），1963 年上海科技出版社出版 | 程门雪："真可靠之叶氏原按也"；精博不及《指南》《存真》，"而特有之好处，亦二书所未有也"（**转述**） |
| **《叶氏医效秘传》**三卷、《三家医案合刻》三卷 | 前者题"叶桂述，吴金寿校"，1831 刊，补入《温热论》，著作权**待考**；后者吴子音辑（1831），卷一叶桂、卷二缪遵义、卷三薛生白 | 后者凡例称叶案"俱当时门诊为多……议论超迈，立法精到" |
| 其他题叶氏之作 | 《本事方释义》（乾隆十年自序，1803 由曾孙叶钟等校刊）、《景岳发挥》《本草经注》《幼科心法》《眉寿堂方案选存》等；考订见百拇医药《叶桂考略》、曹炳章《中国医学大成总目提要》 | 柳序称《景岳发挥》"言多愤激，似非著作体裁"，《本草经注》《本事方释义》"绝少精意，似亦非先生手笔"，疑门弟子"托其名" |

**总评（柳序）**："其生平精力，殚于治病，未遑有所著述。世传医案数种，亦非其所手定，其中**真赝相参，瑜瑕不掩**。"→ 传世文献皆"弟子—后裔—私淑者"三层整理之间接文本，宜作**接受史文献**读。

## 五、外部评价

**同时代及近亲（一手／近一手）**
- 沈德潜《叶香岩传》："以是名著朝野，即下至贩夫竖子，远至邻省外服，无不知有叶天士先生，由其实至而名归也。""切脉望色，听声写形，言病之所在，如见五脏症结。""或于无病时预知其病，或预断数十年后皆验。"
- 石韫玉（道光丙申，本地）："至今谈方术者，必举其姓字，以为仲景、元化一流人也。"
- 胡国英（道光丙申，本地）："自叶香岩先生，治称神术，百余年来，无有继其传者。"
- 叶万青（本地）："先哲之所以享重名者，久而弥光。"

**官修史与地方志（二手）**
- 《清史稿》：**"大江南北，言医者辄以桂为宗，百余年来，私淑者众。最著者，吴瑭、章楠、王士雄。"**又谓"治病多奇中……传闻附会，往往涉于荒诞，不具录"。
- 道光四年《苏州府志》卷一百六、嘉庆二十五年《吴门补乘》卷六均立叶桂条（转引潘华信 1992）。

**"天医星"之称**：现存最早完整记载出梁章钜《浪迹丛谈》卷八"叶天士遗事"：传江西张真人过吴中病殆，服叶方而愈，叶密请其某日过万年桥时"稍一停舆，谓让桥下天医星过去"，"城内外遂喧传天士为天医星矣"。梁氏自注："世称天士为天医星，**亦非真有确据**。"→ 该称号系传说与口碑之合成，引用须注明属传说层。

**争议**
1. **徐灵胎批**：以通行本附批流传（本地"徐评"69 处即其痕迹），对"治疟禁用柴胡"等法度多有掊击，亦推许其幼科"和平精切，字字金玉"。
2. **陆九芝**（晚清）：《世补斋医书》批"温邪上受""温热须究三焦"，主"阳明为成温之薮"，为"寒温之争"中最集中的反调。
3. **文献真伪**：柳序"真赝相参"、四库馆臣"未必尽桂本意"、胡震远"编者皆非弟子"三说并存。而《清史稿》以"传闻附会，往往涉于荒诞，不具录"存史法，最应沿用。

## 六、与同时代／稍晚医家的对比

| 对象 | 关系与依据 |
|---|---|
| **薛生白（薛雪，1681—1770）** | 同里齐名，"名亚于桂"；学术互补——世称"温热看叶天士，湿热看薛雪"；清史稿记其"生平与桂不相能，自名所居曰**扫叶庄**，然每见桂处方而善，未尝不击节也"；"踏雪斋"相讥属**传说** |
| **吴鞠通（吴瑭，1758—1836）** | 稍晚私淑，非及门："学本于桂，以桂立论甚简……著《温病条辨》以畅其义"（清史稿）。叶开纲领，吴备方药，为同一学派前后两阶段 |
| **章楠、王士雄（孟英）** | 章楠取叶论附《伤寒论》后，谓"足以补仲景之残阙"；王孟英《温热经纬》"以轩岐仲景之文为经，叶薛诸家之辨为纬" |
| **徐灵胎（徐大椿，1693—1771）** | 同时代相诘难的经方派，主"明伤寒之理"，与叶氏"治法分途"说正面冲突 |
| **缪遵义** | 乾隆二年进士，因母病通医、弃官为医，"吴中称三家"（叶、薛、缪） |

**小结**：叶学在同代以"互补"（薛）、后世以"私淑—体系化"（吴、章、王）延续，并伴随经方派批评与真伪之辨。
