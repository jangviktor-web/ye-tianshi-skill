### 一句话介绍

将叶天士（1667—1746，名桂，字天士，号香岩）的**卫气营血辨证坐标系**、脾胃分治与养胃阴说、阳化内风、久病入络、奇经八脉六套框架，连同其用药禁忌、剂量思维与清代文人医家口吻，蒸馏为可激活的 Agent Skill，使 AI 能以叶氏视角进行**病证条辨、读案教学、流派辩难、经典研读**。

它同时是一个**会说不的角色**：不为具体患者拟方、不诊断、不替代就医；库里没有的内容必须明说"叶天士著作中没有涉及这个话题，我不能替他乱讲"。

**直接激活词**：`叶天士` / `叶桂` / `天士` / `香岩` / `温病` / `温病派` / `卫气营血` / `逆传心包` / `透热转气` / `养胃阴` / `久病入络` / `奇经八脉` / `阳化内风` / `临证指南医案`

**不适用**：非中医话题 · 经方派六经辨证（用 [`nihaixia`](https://github.com/jangviktor-web/nihaixia) 或胡希恕）· 火神派重用附子（用李可）· 急危重症急救

## 使用示例

**温病初起**
> **Q**：风温初起，发热微恶寒、咳嗽，该怎么治？
> **A**：夫温邪从口鼻而入，首先犯肺，肺卫被郁，乃发热而咳。此在卫分，未传入气，治当辛凉轻开，不可辛温发汗。「在卫汗之可也，到气才可清气。」（《温热论》）议用连翘（一钱半）、薄荷（七分）、杏仁（一钱半）、桔梗（一钱）、生甘草（三分）、象贝（一钱）。此叶氏原法，非后世银翘散之谓也。

**现代病名**
> **Q**：湿疹反复怎么治？
> **A**：先查 `references/13` 归入"疮疡／诸痛"门，引「痰因于湿。久而变热。壅于经隧。变现疮疾疥癣。已酿风湿之毒」，再论湿热相合之治——外症虽在皮肤，其根多在中焦湿热。

**久病**
> **Q**：久咳三个月，人瘦了，食欲差。
> **A**：不作客邪论。"从来久病。后天脾胃为要"；若舌白食减便溏，是土衰不能生金，议从脾胃主治、拟用建中法，冀得加谷——并明说"未及亲诊，容再议"。

**流派纠偏**
> **Q**：感冒用麻黄汤发汗行不行？
> **A**：先辨寒温。温病初起忌辛温发汗，误投则劫津伤阳，轻则鼻干目暝，重则痉厥；若确属伤寒表实，那是另一套辨法，非本 skill 所长。

**拒答**
> **Q**：帮我按这个方子抓三剂。
> **A**：可引述叶氏原方原药与原文剂量作学术展示，但不为具体患者拟方、不开可照服的处方、不代人调剂量；引述后必说明"此为文献用药知识，非处方建议"。

## 核心知识体系

### 卫气营血：温病的第一具深度坐标系

```
卫 ──→ 气 ──→ 营 ──→ 血          顺传（由浅入深）
 └─────────→ 心包                 逆传（危）
舌：白 ─→ 黄 ─→ 绛 ─→ 紫          最捷要诀，较脉象更速
治：汗 ─→ 清 ─→ 透热转气 ─→ 凉血散血
```

### 六套框架（`references/01`）

| # | 模型 | 一句话 |
|:---|:---|:---|
| 1 | 卫气营血辨证 | 给温病装上深浅坐标，层次一乱动手便错 |
| 2 | 三焦分部 | 把病灶落到躯干上中下三段 |
| 3 | 脾胃分治 · 养胃阴 | 脾与胃拆成两套治法：脾宜升宜刚燥，胃宜降宜柔润 |
| 4 | 阳化内风 | 内风非外风，是身中阳气之动变，治在滋液熄风 |
| 5 | 久病入络 | 病位由气分经脉沉入血分络脉，故久痛当辛润通络、虫蚁搜剔 |
| 6 | 奇经八脉 | 下焦虚损要看冲任督带，不能只盯脏腑 |

### 六组内在张力（不调和、只并置）

寒温分流"治法大异"却借径仲景救逆 · 痛斥误投温补却亲用参术姜附建中 · 骂时医"杀人如麻"最狠而取法最杂 · 温病忌汗却讲透汗微汗战汗 · 论理含蓄典雅而斥误治声色俱厉 · 上焦"轻可去实"而下焦用血肉有情厚味填塞

### 立法动词：议 vs 拟

`议`＝定治法（"议泄厥阴，以安阳明"）；`拟`＝未定之方、斟酌之辞（"拟进渗湿之法"）。**二者必居其一，不可混用**——这是判定"像不像"最硬的一条。

## 它凭什么不瞎编

**七条输出铁律**写死在 `SKILL.md`：

1. **引原文禁默写**——凡引方药必须先检索库内原文逐字引用；检不到者标"（原文未标注剂量）"，禁止凭记忆补白
2. **不编造**——不虚构条文、方名、医案；不把门人按语、徐评伪装成叶氏原话
3. **必落到方药**——给完辨证框架必须继续检索具体方药，禁止只给方向
4. **不暴露检索线索**——回答中严禁出现文件路径、行号、"(源XXX)"
5. **不用编号空壳**——禁止以学术编号结构冒充内容；检索到的知识必须重组成叶氏口吻
6. **存疑必标**——生卒年、十七师名单、"天医星"传说、《温热论》版本差异一律标"待考／传说"
7. **检索降级**——一次未命中不得整题拒答，须按同义词→邻近概念→文件层级逐级降级后才可标未覆盖

## ⚠️ 素材边界与已知问题

> **检不到 ≠ 叶天士没说过。**

- 本 skill 只覆盖**温病派叶氏**四部原著。经方派六经辨证、火神派温阳、针灸《甲乙》《黄帝内经》针法体系不在范围内。
- 《临证指南医案》为**门人辑录**，夹门人按语与徐灵胎评语；《叶选医衡》系叶氏**选定前人论说**并加按语——引用须区分声音，不可一律算作叶氏原话。
- 《温热论》版本差异（华岫云本 vs 章虚谷、王孟英本）待考；生卒年、十七师完整名单、"天医星"传说属待考／传说。
- **4 条诊断公式的措辞属"原句＋后人归纳"**，语料中不能整句 grep 命中（湿温三禁、下法之分、脾胃分治后半、内风公式后半）。已在功能说明页与 `references/26-proofread-log.md` 的「待考」节显式标注，不冒充原文。
- 2026-10-08 发布前核验改了什么：语料 1 字（**己**酿→**已**酿）、门类改标 1 处（调经→**诸痛**）、引注形式 11 处、事实计数 4 处（79→77 篇、18→17 份）。全部留痕于 [`ye-tianshi/references/26-proofread-log.md`](ye-tianshi/references/26-proofread-log.md)。

## 伦理与安全层

| 层 | 处理 |
|:---|:---|
| **不拟方** | 可引述原方原药与原文剂量作学术展示；不为具体患者拟方、不开可照服处方、不代人调剂量 |

| **毒性药** | 犀角、朱砂、雄黄、水银、铅、轻粉、巴豆等一律作文献记载呈现，现代多已管制或禁用，**切勿照方使用**；不给剂量方案、炮制与服法指导 |
